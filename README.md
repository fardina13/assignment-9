# DriveFleet

DriveFleet is a simple car rental platform where users can explore available cars, view car details, and book cars for their trips.

**Live Site:** `https://your-live-site-url.com`

## Features

* Browse a collection of available rental cars.
* Search cars by name and filter them by category.
* View detailed information about each car, including price, seats, fuel type, and images.
* Users can create an account and log in using email/password or Google authentication.
* Users can book a car by selecting their preferred rental date.
* A separate **My Bookings** page allows users to see their bookings.
* Users can cancel a booking when needed.
* Car owners/admin users can add and update car information.
* Responsive design for desktop, tablet, and mobile devices.
* Clean and simple interface focused on making car rental easier.

## Technologies Used

* Next.js
* React
* Tailwind CSS
* HeroUI
* Node.js
* Express.js
* MongoDB
* Better Auth

## Project Highlights

DriveFleet was built as a full-stack project with a separate frontend and backend. The frontend communicates with the Express API for car and booking data, while MongoDB is used to store the application data.
